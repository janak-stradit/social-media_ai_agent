These providers process personal data for us to run {product}. Each is bound by a contract that limits how it may use the data. We will update this page before adding a new provider that handles customer content.

| Provider | What for | Data it receives | Location |
|---|---|---|---|
| [Amazon Web Services](https://aws.amazon.com/privacy/) | Hosting, database, file storage, and some AI models (Amazon Bedrock) | All Service data | United States |
| [HeyRoute](https://heyroute.ai) | AI text, image and video generation | Briefs, brand profile details, prompts and reference images | See provider |
| [OpenAI](https://openai.com/policies/privacy-policy), [OpenRouter](https://openrouter.ai/privacy), [Google Gemini](https://policies.google.com/privacy) | Backup AI providers, used only if the main one is unavailable | Briefs, brand profile details, prompts | United States |
| [Stripe](https://stripe.com/privacy) | Payments, subscriptions and refunds | Name, email, amount, payment details (entered directly on Stripe) | United States and others |
| Email delivery provider (SMTP) | Sending account, billing and notification emails | Name, email address, email content | See provider |
