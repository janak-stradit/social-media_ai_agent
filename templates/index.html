  1. Step 1: Go to Meta Developers Portal

    Navigate to developers.facebook.com and log in with your Facebook account.

  2. Step 2: Create a Meta App

    Click My Apps → Create App → Select Business type → Enter your App Name.

  3. Step 3: Add Facebook Graph API Permissions

    Under App Settings → Tools → Graph API Explorer, request the following permissions:

    • pages_show_list
    • pages_read_engagement
    • pages_manage_posts
  4. Step 4: Generate Page Access Token & Page ID

    Select your target Facebook Page from the dropdown and click Generate Access Token. Copy the User/Page Access Token and Page ID into the Facebook Connection form above.

  1. Step 1: Convert Instagram Account to Professional / Business

    In the Instagram mobile app, go to Settings → Account → Switch to Professional Account (Business or Creator).

  2. Step 2: Connect Instagram Business Account to Facebook Page

    Open your Facebook Page → Settings → Linked Accounts → Instagram → Connect Account.

  3. Step 3: Get Instagram Account ID via Graph API

    In Graph API Explorer, query GET /me/accounts?fields=instagram_business_account to retrieve your 17-digit Instagram Business ID.

  4. Step 4: Save Instagram Credentials

    Copy your Instagram Handle (@yourbrand), Instagram Business ID, and Meta Access Token into the Instagram connection form.

  1. Step 1: Open LinkedIn Developer Portal

    Go to linkedin.com/developers and click Create App.

  2. Step 2: Request Community Management API Access

    Under the Products tab, request access to Share on LinkedIn and Community Management API.

  3. Step 3: Generate OAuth 2.0 Access Token

    In the Developer Token Generator tool, authorize permissions w_member_social and w_organization_social.

  4. Step 4: Copy Author URN

    Your Author URN looks like urn:li:person:abcdef123 for personal profiles or urn:li:organization:123456 for company pages. Paste it into the connection form.
